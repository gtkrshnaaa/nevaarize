Examples

64 verified example programs

Nevaarize ships with 64 example programs covering algorithms, async, benchmarks, modules, and real-world patterns. All examples are in the examples/ directory.

Verification Scope

Only scripts listed on this page (inside the examples/ directory) have been verified to run correctly. Scripts written outside these examples may work for similar patterns, but are not guaranteed to be free of issues. See examples/verification_report.txt for full test results.

Fibonacci (from algorithm/mathBasics.nva)

// Iterative fibonacci
function fib(n) {
    if (n <= 1) {
        return n
    }
    a = 0
    b = 1
    for (i in Range(2, n + 1)) {
        temp = a + b
        a = b
        b = temp
    }
    return b
}

print("fib(10) =", fib(10))  // 55
print("fib(20) =", fib(20))  // 6765

Bubble Sort (from algorithm/bubbleSort.nva)

function bubbleSort(arr) {
    n = len(arr)
    for (i in Range(0, n)) {
        for (j in Range(0, n - i - 1)) {
            if (arr[j] > arr[j + 1]) {
                temp = arr[j]
                arr[j] = arr[j + 1]
                arr[j + 1] = temp
            }
        }
    }
    return arr
}

data = [64, 34, 25, 12, 22, 11, 90]
bubbleSort(data)
